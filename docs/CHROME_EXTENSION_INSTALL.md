# Chrome 插件下载安装指南（新手版）

这篇说明只解决一件事：把 Job Search Assistant 插件安装到 Google Chrome，并确认它已经连接到正确的后台账号。全程不需要安装 Node.js，也不需要运行代码。

## 开始前准备

请先确认：

- 已安装 Google Chrome；
- Job Search Assistant 后台已经能够打开；
- Chrome 中已经登录 BOSS 直聘；
- 知道自己应该使用哪个 Job Search Assistant 账号。

> **账号安全提醒：** 插件配对到哪个后台账号，就会使用该账号的个人档案、简历和问候语。配对前请确认后台用户名与当前 BOSS 求职者身份一致。不要在别人的 BOSS 登录页面上使用自己的配对码。

## 第一步：下载插件 ZIP

打开项目的 [GitHub 最新版本下载页](https://github.com/a764506248/Job-Search-Assistant/releases/latest)。

1. 滚动到页面底部的 **Assets**；
2. 点击 `job-search-assistant-chrome-mv3.zip`；
3. 等待下载完成。

也可以使用[插件 ZIP 直接下载链接](https://github.com/a764506248/Job-Search-Assistant/releases/latest/download/job-search-assistant-chrome-mv3.zip)。

如果浏览器提示“是否保留此文件”，请选择保留。该 ZIP 是项目自动构建的 Chrome 插件安装包。

## 第二步：解压 ZIP

Chrome 不能直接加载 ZIP，必须先解压。

### macOS

在“下载”目录双击 `job-search-assistant-chrome-mv3.zip`，系统会生成同名文件夹。

### Windows

右键 ZIP 文件，选择“全部解压”，然后点击“提取”。

解压后打开文件夹，应当能直接看到 `manifest.json`。如果只看到另一个同名文件夹，请继续打开内层文件夹，直到看到 `manifest.json`。

## 第三步：在 Chrome 中加载

1. 在 Chrome 地址栏输入 `chrome://extensions` 并回车；
2. 打开页面右上角的“开发者模式”；
3. 点击左上角“加载已解压的扩展程序”；
4. 选择刚才解压、并且里面能看到 `manifest.json` 的文件夹；
5. 页面出现 **Job Search Assistant** 卡片即表示安装成功。

不要选择以下内容：

- 不要选择 ZIP 文件本身；
- 不要选择仓库里的 `apps/extension` 源码目录；
- 不要选择不包含 `manifest.json` 的外层文件夹。

建议点击 Chrome 工具栏右侧的拼图图标，将 **Job Search Assistant** 固定到工具栏，之后更容易查看连接状态。

## 第四步：生成配对码

1. 打开 Job Search Assistant 管理后台并登录正确账号；
2. 进入左侧“安装向导”；
3. 找到“统一浏览器扩展”；
4. 点击生成 6 位一次性配对码；
5. 保持页面打开，配对码只用于当前账号。

## 第五步：在 BOSS 页面完成配对

1. 打开并登录 [BOSS 直聘](https://www.zhipin.com/)；
2. 刷新一次 BOSS 页面；
3. 找到页面右下角“自动投递控制台”；
4. 在“服务地址”中填写后台地址：
   - 后台运行在本机：填写 `http://127.0.0.1:8765`；
   - 后台运行在服务器：填写你平时打开后台所用的地址，例如 `http://服务器IP`，不要填写 `127.0.0.1`；
5. 输入刚才生成的 6 位配对码并点击配对；
6. 看到“已连接”及扩展版本号，即表示配对成功。

如果没有看到右下角控制台，点击工具栏中的 Job Search Assistant 图标；它会定位并展开控制台。

## 第六步：确认安装结果

回到后台“安装向导”，确认以下项目：

- 浏览器扩展：已连接；
- 扩展版本：符合后台最低版本要求；
- BOSS 登录：已通过；
- 默认简历：已经确认；
- 默认投递图片：需要发送图片时必须设置。

然后在扩展控制台选择简历图片策略：

- **发送前确认**：新手推荐，每次确认图片后再发送；
- **自动发送**：任务确认后自动发送默认图片；
- **不发送**：只发送问候语。

首次使用建议先创建一个目标为 `1` 的测试任务，核对企业、职位和问候语无误后再扩大数量。

## 更新插件

项目发布新版本后：

1. 下载新的 ZIP 并解压到新文件夹；
2. 打开 `chrome://extensions`；
3. 删除旧扩展后加载新文件夹，或者用新文件覆盖旧文件夹后点击“重新加载”；
4. 刷新 BOSS 页面；
5. 如果后台显示扩展未连接，重新生成配对码并配对。

不要只下载新版 ZIP 而继续加载旧解压目录。扩展卡片和 BOSS 右下角控制台显示的版本号才是实际运行版本。

## 常见问题

### Chrome 提示“清单文件缺失”

选择错了目录。重新选择直接包含 `manifest.json` 的解压目录。

### BOSS 页面没有控制台

依次检查：扩展卡片是否启用、是否点击过“重新加载”、BOSS 页面是否刷新、当前网址是否属于 `zhipin.com`。

### 一直显示“尚未连接服务”

确认服务地址能够在当前电脑的 Chrome 中打开。远程部署时不能填写 `127.0.0.1`；它代表当前电脑，而不是服务器。

### 配对码无效或过期

回到后台“安装向导”重新生成一次，不要重复使用其他账号生成的旧配对码。

### 后台账号和 BOSS 身份不同

立即停止自动投递，退出错误的后台账号，使用与当前求职者资料对应的账号重新登录并配对。否则可能把另一位用户的经历生成到问候语中。

### Chrome 重启后需要重新安装吗

不需要。只要没有删除扩展文件夹或扩展卡片，Chrome 会保留它。服务重启或令牌失效时可能需要重新配对。
